# Frontend Design Skill

Al disenar interfaces:
1. Usa SIEMPRE los tokens de \src/core/theme\ (Dark Mode First).
2. Asegura tap targets de 44x44 (Apple Human Interface Guidelines).
3. Implementa micro-animaciones con \eact-native-reanimated\ para feedback visual.
4. Usa \lucide-react-native\ con strokeWidth uniforme.
5. No uses text crudo, envuelve en componentes de Typography del core.
